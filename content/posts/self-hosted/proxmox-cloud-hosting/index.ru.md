## Облачный хостинг для 1С:Предприятие на Proxmox

---

#### Клиент
Хостинг-провайдер среднего бизнес-сегмента, предоставляющий инфраструктурные услуги бизнес-клиентам

---

#### Задача
Клиенту требовалась надёжная self-hosted платформа виртуализации для предоставления готовых облачных инстансов 1С:Предприятие как управляемого продукта. Стек включал: кластер Proxmox VE для виртуализации, виртуальные машины на Windows Server с 1С:Предприятие + PostgreSQL + Apache, VM с RouterOS (MikroTik) в качестве маршрутизатора с HAProxy для балансировки нагрузки, сетевую связанность между узлами, репликацию хранилищ и автоматические бэкапы — всё в рамках коммерческой услуги для десятков конечных клиентов.

---

#### Решение

###### 1. Кластер Proxmox VE
- Развёрнут и настроен кластер Proxmox VE на нескольких физических серверах
- Общее хранилище и live migration для высокой доступности
- Изоляция ресурсов и квоты на VM каждого клиента
- Регулярное обслуживание кластера, обновления и планирование ёмкости

###### 2. Сеть и маршрутизация
- VM с RouterOS (MikroTik) в качестве пограничного маршрутизатора и файрвола
- HAProxy для балансировки нагрузки и reverse proxy к бэкенд-VM
- VLAN-сегментация для изоляции клиентов
- VPN-доступ для безопасных административных подключений

###### 3. Шаблоны VM Windows Server
- Golden image шаблон: Windows Server + 1С:Предприятие + PostgreSQL + Apache
- Автоматизированное развёртывание VM из шаблона для новых клиентов
- Плановые обновления Windows и усиление безопасности
- Выделение ресурсов (CPU, RAM, диск) на каждого клиента

###### 4. Репликация и высокая доступность
- Репликация хранилищ на уровне между узлами Proxmox
- Live migration VM для обслуживания без простоя
- Конфигурация failover для критичных нагрузок клиентов

###### 5. Бэкапы и аварийное восстановление
- Автоматические ежедневные бэкапы VM с политикой хранения
- Репликация бэкапов на внешний сервер
- Задокументированные процедуры восстановления, периодически проверяемые
- Мониторинг бэкапов и оповещения при сбоях

###### 6. Мониторинг и поддержка
- Мониторинг инфраструктуры (состояние хостов, VM, хранилищ, сети)
- Проактивные оповещения при исчерпании ресурсов и деградации сервисов
- Многоуровневая поддержка конечных клиентов: обработка инцидентов, тюнинг производительности, масштабирование

#### Результаты
✅ **Предоставление услуги:** десятки клиентов получают готовые облачные инстансы 1С:Предприятие  
✅ **Высокая доступность:** live migration и репликация устраняют единые точки отказа  
✅ **Быстрое развёртывание:** новые VM клиентов разворачиваются из шаблона за минуты
